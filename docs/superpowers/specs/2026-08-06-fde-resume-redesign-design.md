# FDE 方向简历重构设计

- 日期：2026-08-06
- 仓库：`jililuo/resume-site`
- 目标分支：`codex/fde-resume-redesign`
- 目标职位：高级后端工程师，向 FDE / AI 应用交付方向转型

## 1. 目标与边界

本次重构将现有“Java 后端工程师”简历更新为“高级后端工程师｜FDE 方向”。核心目标是让招聘者快速理解候选人的企业级研发基础、复杂业务系统经验、跨技术栈能力和 AI 应用原型实践，同时清晰标注尚未具备医疗生产落地与医院现场交付经验。

所有内容必须可在面试中说明和举证。不得把个人练习包装为生产项目，不得虚构医疗行业、HIS/EMR/LIS 对接、医院驻场、私有化部署、客户培训或项目验收经历。

公开仓库不得包含身份证号、工号、签名、离职证明图片或其他证明材料。婚姻状况和年龄从页面移除。

## 3. 定位方案

讨论过三个方向：

1. 可迁移能力型：直接使用 FDE / AI 应用交付工程师标题。
2. 后端工程师转型型：以高级后端工程师为主标题，明确 FDE 方向。
3. 双版本型：同时提供 FDE 与通用后端两个版本。

选择方案 2。页面主标题为“高级后端工程师｜FDE 方向”，避免对尚未拥有的交付资历作过度承诺，同时保持后端岗位的匹配面。

建议首屏定位文案：

> 近 8 年企业级软件研发经验，覆盖高并发后端、CargoWise 货代业务与日本海关报关模块。正在将复杂业务系统经验延伸至 AI Agent、RAG 与前置交付场景。

## 4. 信息架构

页面按招聘者的扫描顺序组织：

1. 首屏：姓名、目标职位、定位摘要、公开联系方式、头像。
2. 核心数据：近 8 年研发、Java + C#、AI 工程项目与原型经验。
3. 职业概览：教育和工程背景、FDE 可迁移能力。
4. 工作经历：慧咨环球置顶，其次为酷开、南京运享通和思特奇。
5. 能力矩阵：后端与业务系统、数据与部署、AI 应用工程、Agent 工程与 AI 协同。
6. 核心项目：CargoWise 日本海关模块置顶，其次为五菱灯语屏、小维 AI、短信群发和 XPORTS。
7. 页脚：邮箱、电话和动态年份。

旧页面中的主观技能百分比全部移除，改为技术名称、使用场景和项目证据。

## 5. 内容表达规则

### 工作经历

每段经历采用“业务背景 + 个人职责 + 工程动作”的表达，不编造量化结果。CargoWise 经历重点体现复杂行业规则理解、C# / WinForm 企业软件开发、存量系统维护和工具升级。

### AI 能力

Dify 工作流、Milvus 内部知识库 RAG 与知识图谱按小维 AI 项目经验呈现；LangChain、LangGraph 等个人练习按原型范围表达。不得虚构医疗用途、数据规模、准确率或生产指标。

### FDE 可迁移能力

使用以下真实能力建立转型叙事：

- 复杂行业业务规则理解与实现
- 企业级存量系统维护升级
- Java、C#、Python 跨技术栈适应
- 数据库、Linux、Docker、Nginx 与前端能力
- Claude Code Agent 机制研究、内部定制 Agent 开发和 Coding Agent 协同

不使用“医疗交付专家”“医院系统集成经验”等表述。

## 6. 视觉设计

选择“A 证据型编辑简历”。

视觉方向为专业编辑式纸张排版：暖白背景、炭黑正文、克制的砖红主强调色和少量金色证据标记。设计强调阅读效率、可信度和打印表现，不采用深色控制台风或过度装饰。

- 最大内容宽度约 980px
- 正文使用清晰的中文无衬线字体
- 姓名、章节标题使用中文衬线字体
- 技术标签使用等宽字体
- 卡片圆角不超过 4px
- 用横线、编号和留白建立层级，避免大量漂浮卡片
- 桌面端适度双栏，移动端改为单栏
- 头像保留现有公开 URL
- 移除年龄和婚姻状态
- 首屏不使用超大满屏 Hero，确保下一段内容在首屏可见

## 7. 交互与响应式

维持纯 HTML、CSS 和少量原生 JavaScript：

- 固定导航与当前章节高亮
- 锚点平滑滚动
- 轻量滚动淡入
- 支持 `prefers-reduced-motion`
- 移动端提供可访问的导航，不隐藏关键正文
- 邮箱、电话和 GitHub 链接可直接操作
- 不增加运行时框架或构建依赖

## 8. 打印设计

增加 `@media print`：

- 隐藏固定导航、动画和非必要装饰
- 使用白色背景和高对比文字
- 控制分页，避免经历或项目卡片被截断
- 展开全部内容
- 保留可识别的链接文本
- 允许浏览器直接导出整洁 PDF

## 9. 技术实现

继续维护单文件 `index.html`，使用语义化 HTML5、CSS Custom Properties、Grid/Flexbox 与 Intersection Observer。同步更新 `SPEC.md`，使其与最终设计一致。

不引入 React、Vue 构建流程或第三方动画库，确保 GitHub Pages 直接发布。
